## Primary compression

Runtime is the bounded operational owner for:

```text
Operational Commitment
  -> Admission / Binding
  -> Attempt / Realization
  -> Effect / Evidence
  -> Scoped Claim
  -> Standing / Reconciliation
```

## Cross-cutting review dimensions

Every material Runtime claim should be reviewable along four dimensions:

- **Identity** — exactly which Operation, Attempt, realization, effect, evidence or generation is being discussed?
- **Scope** — where, for whom, for how long and under which participant/topology/authority boundary does the claim hold?
- **Support** — what evidence, mechanism, authority or contract justifies the claim?
- **Standing** — is that support still current, valid and operationally usable now?

This four-part compression is a programme review grammar, not a replacement for the canonical Foundation Families.
